# A4 + 4090 source synchronization

This tree merges actual working source from A4 and 4090, including uncommitted
and untracked source. Both source workspaces were based on eee36cb.
GitHub rl-co-online and the previous rl-co-online-wyh are NOT additional source
inputs. The personal branch is only the publication destination.

## Resolution policy

All eleven conflicted files use A4 in full. Every captured A4 source file is
byte-identical except pre_start_ray.sh, whose node rank was explicitly changed
from 0 to 1. Non-conflicting 4090 changes and unique files are included.
See the accompanying JSON manifest for hashes of snapshot commits and decisions.

## Machine-local startup scripts

- Root pre_start_ray.sh and scripts/hosts/pre_start_ray_a4.sh preserve A4 settings
  with node rank 1.
- scripts/hosts/pre_start_ray_4090.sh preserves the existing 4090 script.
- Each deployed checkout keeps its machine-specific root pre_start_ray.sh.
  A tracked local modification of that script is expected.
- 4090b has no previous startup script; its copy uses its own repository path
  and LAN network interface. Its Python environment still needs installation.

Deployment paths:
- 4090: /home/ubuntu/wangyinghan/RLinf-wyh
- 4090b: /home/franka/wangyinghan/RLinf

Existing source directories, datasets, model weights and runtime environments
are retained. This operation does not start Ray, training, or robot services.
The A4 source directory receives only the requested startup node-rank change.

## Validation and limits

Using the existing 4090 Python 3.11 training environment:
- Merged: 126 passed, 16 failed, 1 skipped, 2 collection errors.
- A4 source snapshot: 90 passed, 1 failed, 1 skipped.
- 4090 source snapshot: 36 passed, 15 failed, 2 collection errors.
- The merged failure/error identifiers equal the union of source baseline
  failures/errors. No additional failure was observed in these suites.

The A4 failure is a stale experiment assertion (gripper logstd -1.5 versus
configured -1.3). The 4090 failures include tests referring to APIs absent from
its own source snapshot. They are retained, not silently fixed or removed.
These results are not an all-tests-pass claim. GPU and hardware execution were
not tested. Model/data paths and GPU placements remain the source settings.
